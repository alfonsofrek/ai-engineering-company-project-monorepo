# UI conventions

- Leer `CONTEXT.md` antes de cambiar contenido o validaciones de onboarding.
- Mantener separados `uis/website` y `uis/backoffice`; no importar componentes entre ambas apps.
- Usar solo `Mexico` y `Espana` como opciones de pais en esta fase.
- Mantener copy profesional y orientado a operaciones; no hacer claims no verificables.
- Cada pantalla nueva debe tener estado vacio, error o carga si depende de datos remotos.
