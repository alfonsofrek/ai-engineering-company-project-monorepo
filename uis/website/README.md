# TrackFlow website

Website publico para presentar la operacion de ultima milla de TrackFlow y captar solicitudes de marcas de e-commerce en Estados Unidos y España.

## Ejecutar

```bash
npm install
npm run dev
```

La aplicacion usa Next.js, React, TypeScript y CSS global. El formulario tiene los 12 campos, validaciones y mensajes del briefing oficial (`docs/briefings/01-web-fundamentals.es.md`).
