## Autenticación

Todas las rutas de esta aplicación requieren sesión: el listado y detalle de candidatos, alta, edición y `/account/profile`. `/login` y `/register` son públicas. El token JWT se guarda en `localStorage`, se envía como `Authorization: Bearer` en las solicitudes protegidas y se elimina al cerrar sesión o recibir `401`.

La autenticación usa `/auth`, `/users` y `/profiles` de `services/api`. Inicia primero esa API y configura `API_INTERNAL_URL` para las llamadas de autenticación; configura `NEXT_PUBLIC_API_URL` con el origen de la API que sirve los registros de candidatos. El website público de TrackFlow permanece sin guard ni cambios.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
